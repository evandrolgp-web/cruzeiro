# Cruzeiro Notícias

Agregador de notícias do Cruzeiro Esporte Clube em tempo real.

🌐 **Site:** [evandrolgp-web.github.io/cruzeiro](https://evandrolgp-web.github.io/cruzeiro/)

## Fontes

- Globo Esporte
- Central da Toca
- No Ataque
- Super Esportes
- Site Oficial do Cruzeiro
- Google Notícias

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).
